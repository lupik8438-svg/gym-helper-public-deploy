## 🚀 Как пользоваться

### Telegram Bot:
1. Открой Telegram
2. Найди: **@gymhelperrussia_bot**
3. Нажми `/start`
4. Используй команды:
   - `/profile` - твой профиль
   - `/bmi` - рассчитать индекс массы тела
   - `/calories` - рассчитать калории и БЖУ
   - `/supplements` - рекомендации по добавкам
   - `/weight` - добавить вес
   - `/food` - добавить еду
   - `/progress` - посмотреть график

### Локальный сайт:
1. Открой: [http://localhost:5001](http://localhost:5001)
2. **Главная** - обзор возможностей
3. **Калькуляторы** - BMI, калории, добавки
4. **Сканер еды** - анализ продуктов

## 📊 Доступные калькуляторы

### 1. BMI (Индекс массы тела)
- Расчет по формуле: `вес / (рост/100)²`
- Категории: недостаточный, нормальный, избыточный вес, ожирение
- Рекомендации по здоровью

### 2. Калории и макронутриенты
- BMR (базовый метаболизм) по формуле Mifflin-St Jeor
- TDEE с учетом уровня активности
- Расчет БЖУ под цель (похудение/поддержание/набор)

### 3. Спортивное питание
- Креатин
- Протеин
- BCAA
- Омега-3
- Витамин D
- Магний
- Приоритеты и дозировки под цель

### 4. Сканер продуктов
- База популярных продуктов
- Калории, белки, жиры, углеводы
- Расчет на указанный вес
